# Theme Editor icon

`ThemeEditor.png` is the source artwork. `ThemeEditor.icns` contains the standard
macOS icon sizes, including Retina representations, and is bundled with the app.
The current design uses the TextMate flower and a pencil, with a transparent
background. It replaces the earlier rainbow design.

Created with the built-in image-generation tool using
`Applications/TextMate/icons/TextMate.icns` as the reference (converted to PNG).

## Generation prompt

Use case: precise-object-edit. Edit this exact original TextMate application icon. The user wants the icon IDENTICAL to the original TextMate icon, with only a pencil added. Keep the existing purple flower exactly unchanged: identical petals, identical number and shapes of petals, identical photographic texture, identical dark central disc, identical color and brightness, identical size and position on the square canvas. Do not redraw, reinterpret, enlarge, shrink, recolor or restyle the flower. Keep all original flower pixels and its transparent silhouette wherever the new pencil does not overlap. Add one realistic yellow wooden pencil over the top-right corner, diagonally pointing down-left, with a graphite tip near (65%, 34%) and a silver ferrule/pink eraser near (94%, 5%). Pencil should read clearly at small icon sizes, around 8% of the canvas width, covering only the upper-right petals. All pencil parts must remain inside the canvas. Preserve original transparent background; absolutely NO background tile, NO rainbow, NO square badge, NO additional shadow around flower, NO text. Output same 1024x1024 square layout with actual alpha transparency. The only addition is the pencil.
